# Recursos Estáticos Offline do MaxTerminal (`CA-43`)

Este diretório armazena recursos empacotados junto ao binário Tauri para operação 100% offline:
- Hooks de Shell Integration (`zsh`, `bash`, `fish`) embutidos via `include_str!` / `mt-shell`
- Esquemas de cores padrão (`Max Navy/Teal`) embutidos via `mt-themes`
- Migrações SQLite e dicionários FTS5 embutidos via `mt-db`
